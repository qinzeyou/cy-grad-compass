# MVP 设计说明

## 目标

建立一个单机单用户工具，完成“导入本地代码模板 → 复制生成项目 → 管理项目 → 查看统计”的最短闭环。

## 功能范围

首版包含模板导入、项目生成、项目列表、状态管理和统计卡片。用户在生成项目时选择目标目录，应用只复制目录并登记路径，不修改代码、不执行安装或 Git 初始化命令。

项目状态固定为：`进行中`、`已完成`、`已归档`。

## 数据模型

```text
Template: id, name, storedPath, createdAt
Project: id, name, path, status, templateId, createdAt, updatedAt
```

数据库与模板目录统一放在 Electron `app.getPath('userData')` 下。项目代码目录由用户选择，应用只保存路径。

## 技术边界

- React + TypeScript：渲染进程界面；
- Electron 主进程：窗口、目录选择、复制目录、打开路径；
- preload：白名单 IPC；
- SQLite：模板与项目持久化；
- Word 说明书、详细学生字段、任务阶段、多模板和云同步后置。

## 验收标准

1. 原模板目录删除后，仍可使用应用模板副本生成项目；
2. 应用重启后项目与统计数据仍存在；
3. 状态修改后统计卡片同步；
4. 项目路径可在系统文件管理器中打开；
5. 复制失败时保留原目录并显示错误。
